# Interface e Estilos (`index.html` & `styles.css`)

Define a estrutura HTML da aplicação e o design system em CSS.

## Destaques
- **`styles.css`**: Contém variáveis de cores (incluindo `--status-critical-color` e `--status-normal-color`), estilização de cartões, botões, modais e responsividade.
- **`index.html`**: Contém os containers principais, barras de navegação, modais e scripts com controle de versão de cache (`?v=2`).
